## Visão Geral

### O Problema

Desenvolvedores, freelancers e PMs **não têm ferramenta integrada** para rastrear produtividade.

Hoje eles usam:

- ❌ Notion (separado de GitHub)
- ❌ Excel (manual)
- ❌ Múltiplas ferramentas (fragmentado)
- ❌ Sem insights automáticos

### Nossa Solução

✅ **Um lugar único** para toda produtividade  
✅ **Integrado** (Notion + GitHub + mais)  
✅ **Inteligente** (AI + Recomendações)  
✅ **Acessível** (preço justo)

### Target Market

**Primary**: Desenvolvedores Junior/Mid ($0-5K/mês)  
**Secondary**: Freelancers ($2K-10K/mês)  
**Tertiary**: PMs/Scrum Masters

**TAM (Total Addressable Market)**: ~500K devs em Brasil + LATAM

## Planos de Preço

### Free Plan

**Preço**: R$0/mês (Freemium)

**Features**:

- Dashboard básico
- 1 integração (GitHub OU Notion)
- 30 dias de histórico
- Relatórios em PDF
- 2 KPIs simultaneamente
- Max 1 usuário
- Community suporte

**Objetivo**: Onboarding + Viral loop

---

### Pro Plan

**Preço**: R$29-39/mês ($6-8 USD)

**Features** (Free +):

- Dashboard completo
- 5 integrações (GitHub, Notion, Slack, Calendar, Email)
- 12 meses de histórico
- Comparação mês a mês
- KPIs ilimitados
- Max 1 usuário
- AI Insights (básico)
- Notificações avançadas
- Export em múltiplos formatos
- Email suporte (24h)

**Target**: Devs individuais + Freelancers

---

### Team Plan

**Preço**: R$99/mês ($20 USD) + R$29/user adicional

**Features** (Pro +):

- Max 5 usuários na equipe
- Dados compartilhados entre time
- Permissões granulares
- Dashboard do time
- Relatórios compartilhados
- Comentários em KPIs
- Integrações ilimitadas
- Mobile app prioritário
- Webhook API (básico)
- Priority suporte (2h)
- 25 GB de storage

**Target**: Pequenos times (2-5 pessoas)

---

### Enterprise Plan

**Preço**: Custom (nego por volume)

**Features** (Team +):

- Usuários ilimitados
- Storage ilimitado
- SSO/SAML
- API access completo
- Webhooks ilimitados
- Custom branding
- Data residency (escolher região)
- SLA 99.9% uptime
- Dedicated account manager
- Treinamento customizado
- 24/7 suporte

**Target**: Empresas (20+ pessoas)

## Análise Competitiva

### Competidores Diretos

#### ✅ Notion

**Preço**: Free, Plus $10/mês, Teams $25/mês

**Forças**:

- Popular entre devs
- Muito flexível
- Grande comunidade

**Fraquezas**:

- Sem integração GitHub
- Lento para produtividade
- UI complexa

**Nossa vantagem**: Integrado GitHub + AI insights

---

#### ✅ Toggl Track

**Preço**: Free, Plus $10/mês

**Forças**:

- Time tracking especializado
- Relatórios bons
- Integrações muitas

**Fraquezas**:

- Foco em time tracking
- Caro para features básicas
- Não integra Notion

**Nossa vantagem**: Mais barato + Notion integration

---

#### ✅ RescueTime

**Preço**: Free, Premium $9/mês

**Forças**:

- Automático (sem logar)
- Análises detalhadas
- Distraction blocking

**Fraquezas**:

- Apenas tracking
- Sem projetos/OKRs
- Interface desatualizada

**Nossa vantagem**: OKRs + Growth mindset

## Modelo de Receita

### Fonte de Renda #1: SaaS Subscriptions (95%)

```
MRR = (Pro users × $29) + (Team users × $99 + per-user) + (Enterprise custom)

Projeção:
├─ Mês 1 (Lançamento): 50 Pro users = $1,450
├─ Mês 3: 150 Pro + 10 Team = $5,320
├─ Mês 6: 300 Pro + 30 Team = $11,870
├─ Mês 12: 500 Pro + 100 Team = $18,200
└─ Mês 24: 1000 Pro + 300 Team + Enterprise = $50K+
```

### Fonte de Renda #2: Marketplace (5% - v3.0+)

```
Developer revenue share: 30% do preço do template
┌─ 50 templates × $20 médio = $1000 revenue
├─ Comissão KPI Dashboard: 30% = $300
└─ Developer recebe: 70% = $700
```

### Fonte de Renda #3: Enterprise Support

```
- Onboarding: $500-1000
- Treinamento: $100/hora
- Custom development: $150/hora
- SLA premium: +30% subscription
```
